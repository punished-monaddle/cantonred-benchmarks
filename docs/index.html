Like-for-like measurements

A series holds workload, host, harness, participant version, storage and instrumentation constant. The synchronizer revision may vary. Imported runs with unknown host identity remain separate.

Read instrumented runs as diagnostics

Tracing and profiling affect timings. Instrumented and uninstrumented runs never share a series. CPU and RSS cover the synchronizer; command latency includes the wider transaction path.
